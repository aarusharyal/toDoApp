# toDoApp

A simple to-do list application for organizing and tracking daily tasks.

## Features

- Add new tasks
- Mark tasks as complete
- Remove tasks
- Keep your task list organized

## Getting Started

1. Clone the repository:

	```bash
	git clone <repository-url>
	```

2. Open the project directory:

	```bash
	cd toDoList
	```

3. Follow the setup instructions for the project's framework or runtime, then start the application.

## Usage

Create a task, update it as its status changes, and remove it when it is no longer needed.
